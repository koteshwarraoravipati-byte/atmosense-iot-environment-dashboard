COLLEGE PROJECT REPORT

Atmosense

IoT environmental intelligence using ESP32, DHT11, OLED, AWS IoT Core, MQTT over TLS, and a responsive browser dashboard.

Abstract

From physical sensing to useful insight

Atmosense measures temperature and relative humidity, displays readings locally, transmits telemetry securely, stores timestamped history, visualizes trends, and warns users when configurable thresholds are crossed.

System architecture

How the system works

DHT11 sensor→ESP32→AWS IoT Core MQTT/TLS→Node.js ingestion→Atmosense dashboard
01

Measure

The DHT11 captures temperature and relative humidity. The SSD1306 OLED gives a local reading for quick verification.

02

Secure

ESP32 and the dashboard use certificate-based MQTT/TLS connections with separate least-privilege policies.

03

Act

History, device management, CSV export, and threshold alerts turn raw sensor values into decisions.

Components

Hardware and software

  • ESP32 DevKit V1 / NodeMCU-32S
  • DHT11 temperature and humidity sensor
  • 0.96-inch SSD1306 I²C OLED
  • AWS IoT Core and MQTT over TLS
  • Node.js, Express, and Server-Sent Events
  • Responsive PWA dashboard with optional Supabase Auth

Limitations and future work

Responsible deployment

The public demonstration starts in sample-data mode. Live hardware requires private AWS certificates and MOCK_DATA=false. Public multi-user deployment should use Supabase Auth, Supabase/Postgres telemetry storage, row-level security, rate limiting, and managed alert delivery.
